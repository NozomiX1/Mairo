# Super Mario JS — 网页版马里奥

一个纯原生 JavaScript + Canvas 实现的横版马里奥，所有像素画、音效、音乐均由代码实时生成，
**零外部资源、零依赖**。双击 `index.html` 或本地起任意静态服务器即可游玩。

## 运行方式

- 直接用浏览器打开 `index.html`（Chrome / Edge / Firefox 均可），或
- `npx serve .` / `python -m http.server` 后访问对应地址。

## 操作

| 按键 | 功能 |
| --- | --- |
| ← → / A D | 移动 |
| Z / K / 空格 / ↑ | 跳跃（长按跳更高） |
| X / J / Shift | 加速奔跑（跑动时跳得更高） |
| ↓ / S | 蹲下（大形态） |
| P | 暂停 |
| M | 静音 |
| Enter | 开始 / 确认 |

触屏设备会自动显示虚拟按键（◀ ▶ / B 加速 / A 跳跃）。

## 还原的玩法机制

- **吃蘑菇变大**：顶 `?` 块弹出蘑菇，吃下后马里奥变大（+1000 分），变大动画期间无敌。
- **踩怪物**：踩扁栗子怪（Goomba）、踩绿龟（Koopa）变成龟壳；连续踩踏得分依次翻倍
  （100 → 200 → 400 → 800 → 1000 → 2000 → 4000 → 8000）。
- **龟壳连击**：踢出龟壳可以撞飞一排敌人（每个 500 分），壳撞墙会反弹，静置约 7 秒后
  会苏醒复活。
- **顶砖块**：小马里奥顶砖只会弹动；**变大后顶砖直接撞碎**（碎块四散飞溅，+50 分）。
- **顶块震敌**：顶块时正好站在块上方的敌人会被弹飞。
- **受伤变小 / 无敌闪烁**：大形态受伤缩回小形态并获得短暂无敌；小形态受伤即死亡。
- **可变跳跃**：长按跳跃键跳更高，奔跑中起跳更高更远（还原原版惯性物理）。
- **金币 / 计分 / 时间**：顶 `?` 块出金币（+200）、收集 100 枚金币奖 1 条命；
  关卡 300 单位倒计时，通关时剩余时间按 50 分/单位快速结算。
- **旗杆通关**：抓杆下滑（按位置给奖励分）、旗子降落、走进城堡、时间结算、COURSE CLEAR。
- **死亡与生命**：踩空掉坑 / 时间耗尽 / 碰敌（小形态）死亡，共 3 条命，耗尽 GAME OVER。
- **镜头**：仅向右卷动的经典镜头，玩家不能向左走出屏幕。
- **场景**：1-1 风格关卡 —— 四根高低管道、三个深坑、高空砖排与隐藏路线、终点大阶梯、
  城堡，以及视差云 / 山丘 / 灌木装饰。

## 技术说明

- 原版 NES 分辨率 256×240 渲染，CSS 放大并 `image-rendering: pixelated` 保持像素锐利。
- 固定 60FPS 步长积分（累加器模式），帧率波动不影响手感。
- 所有精灵来自手工逐像素字符矩阵（见 `js/sprites.js`），tile 美术为程序化绘制。
- 音效与背景音乐由 Web Audio API 实时合成（`js/audio.js`），BGM 为原创的致敬旋律。

## 文件结构

```
index.html        页面壳 + 触屏按键
js/audio.js       合成音效 + 8-bit BGM 序列器
js/sprites.js     像素精灵（马里奥大/小、敌人、道具）+ 3x5 像素字体
js/level.js       tile 定义、tile 美术、1-1 风格关卡数据
js/entities.js    玩家物理与实体 AI（Goomba / Koopa / 蘑菇 / 粒子）
js/game.js        状态机、碰撞、镜头、渲染、HUD、输入
```
