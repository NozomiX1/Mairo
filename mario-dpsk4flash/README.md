# Super Mario Bros. — Web 版

一个用原生 HTML5 Canvas + JavaScript 从零实现的「超级马里奥」网页游戏，
复刻 SMB World 1-1 的布局与玩法，无任何外部资源（图片 / 音频均为代码实时生成）。

## 运行

直接双击打开 `index.html` 即可游玩（无需安装任何东西），
或启动本地服务器：

```
python -m http.server 8000
```

然后浏览器访问 <http://127.0.0.1:8000>。

## 操作

| 按键 | 功能 |
| --- | --- |
| ← → / A D | 移动 |
| Z / K / 空格 / ↑ / W | 跳跃（轻点小跳，按住满跳） |
| X / L / Shift | 加速跑 |
| R | 重开本关 |
| P | 暂停 |
| M | 静音 / 恢复声音 |
| Enter / 点击画面 | 开始 / 继续 |

触屏设备自动显示虚拟按键（左：◀▶，右：A/B）。

## 还原的特性

- **吃蘑菇变大**：顶出蘑菇，变大后能顶碎砖块（小身板只能顶得砖块弹一下）
- **踩怪物**：踩扁板栗仔（Goomba），踩乌龟（Koopa）变龟壳，再踩一脚 / 踢出龟壳
- **移动龟壳**能一路撞飞敌人；**移动中的龟壳**会反过来伤你
- **问号砖**：出金币或蘑菇；**隐藏砖**：经典位置的 1UP 绿蘑菇
- **坑/水管/砖楼梯/旗杆/城堡**：按高度计分的终点旗杆，跳上旗杆滑下、走进城堡通关
- 300 秒倒计时、计分（100/200/400/800/1600 连击）、金币计数（100 金币 = 1 条命）、3 条命
- 按住 X/Shift 加速跑、跳得更高更远
- 8-bit 风格音效与背景音乐（Web Audio 合成）：跳跃/金币/踩怪/顶砖/变大/1UP/死亡/通关，以及陆上关卡主题曲

## 技术要点

- 固定步长物理（60Hz 子步进累积），子像素移动与逐轴碰撞解析
- 内部 256×240 分辨率，CSS 像素化放大
- 全部精灵为 ASCII 像素画 + 调色板运行时生成；字体为内置 5×7 位图字体
- 无头测试：`node test/sim.js`（物理/机制单元测试 + 脚本化通关验证）、
  `node test/render_smoke.js`（假 canvas 渲染冒烟）

## 文件结构

```
index.html         入口页面
style.css          样式与触屏按钮
js/font.js         5×7 位图字体
js/sprites.js      像素精灵（ASCII 画 + 调色板）
js/audio.js        8-bit 音效与音乐合成
js/level.js        关卡数据（World 1-1 风格布局）
js/input.js        键盘 + 触摸输入
js/game.js         物理 / 实体 / 碰撞 / 渲染 / 状态机
test/sim.js        无头模拟 + 单元测试
test/render_smoke.js  渲染冒烟测试
```
