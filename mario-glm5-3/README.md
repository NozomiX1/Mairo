# Super Mario Bros. · Web 复刻版

用原生 HTML5 Canvas + Web Audio 制作的《超级马里奥兄弟》Web 复刻版，无任何外部资源
（所有像素画、音效、音乐均由代码生成），还原了原作 World 1-1 的完整玩法。

## 运行方式

直接双击打开 `index.html` 即可（无需服务器、无需联网；联网时会加载更接近原版的像素字体）。

## 操作

| 按键 | 功能 |
| --- | --- |
| ← → | 移动 |
| Z / K / 空格 | 跳跃（按住跳得更高） |
| X / J / Shift | 加速跑 / 发射火球（火焰状态） |
| ↓ | 蹲下（大个时）/ 进入水管 |
| Enter | 开始 / 确认 |
| P | 暂停 |
| M | 静音 |
| R | 回到标题 |

移动端（触摸设备）会自动显示虚拟按键。

## 已还原的原作机制

- **SMB1 物理参数**：加速度/减速度/跑步上限、起跳初速与两段重力（按住跳跃键上升段重力小，
  可变跳跃高度）、高速助跑跳更高等，均按原作数值（60fps 像素/帧）调校
- **蘑菇变大 / 火之花变火焰马里奥**（可发火球，最多同时 2 颗）、受伤降级、变身无敌闪烁
- **顶砖**：问号砖出金币/蘑菇/花；小马里奥顶砖块会顶起，变大后从下方顶碎砖块（四块碎片飞溅）；
  连打金币砖（10 金币）、隐藏 1UP 砖、顶砖可顶死正上方的敌人、弹起正上方的蘑菇
- **踩敌人**：踩板栗仔、踩乌龟变龟壳、踢壳连杀（连锁得分 100→200→400→…→1UP）、
  踩踏连击计分、龟壳撞碎砖块、龟壳苏醒
- **无敌星**：调色板闪烁 + 专属 BGM + 碰敌即杀
- **旗杆通关**：按抓杆高度得分（100~5000）、降旗、走进城堡、剩余时间折算分数、城堡升旗
- **地下奖励房**：第 4 根水管按 ↓ 进入（水管动画），吃金币后从右侧水平水管出来，
  从终点前的水管升回地面，专属地下 BGM
- **1-1 关卡布局**：按原版近似还原（问号砖组合、4 根水管、3 处断崖、8 连砖、
  阶梯、双水管终点、16 板栗仔 + 1 乌龟、山丘/灌木/云朵背景、城堡）
- **其它**：相机只进不退、400 单位倒计时（100 时加速 BGM）、生命/结算/Game Over 画面、
  100 金币加命、金币音效、死亡/通关/游戏结束旋律、背景音乐（地上/地下/无敌星三套）

## 文件结构

```
index.html      入口（画布、样式、触屏按键）
js/sprites.js   像素画精灵数据与调色板烘焙（马里奥×2 尺寸×4 配色、敌人、道具、砖块等）
js/audio.js     Web Audio 合成音效 + 音乐序列器（三首循环 BGM + 四段小曲）
js/level.js     World 1-1 与地下奖励房的瓦片地图构建
js/entities.js  实体类：马里奥物理、板栗仔、乌龟、道具、火球、瓦片碰撞
js/game.js      主循环、顶砖/踩踏/得分规则、相机、HUD、游戏状态机
qa/             开发自检脚本（无头浏览器 ASCII/PNG 转储）
shots/          开发过程中生成的截图
```

## 开发自检（可选）

页面支持若干 QA 参数（无头浏览器下用 `qa/dump.ps1`、`qa/png.ps1` 提取）：
`?sheet=1` 精灵表、`?map=1` 关卡小地图、`?dump=world&demo=1&shot=N` 运行 N 帧后把
画面转成 ASCII、`?dump=world&test=stomp` 等逐项机制测试。
