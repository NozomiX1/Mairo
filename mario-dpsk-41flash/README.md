# Super Mario - Canvas Edition

一个用原生 JavaScript + Canvas 从零实现的网页版超级马里奥，无任何第三方依赖、无外部资源（精灵图是代码里手写的像素画，音乐音效是 WebAudio 实时合成的）。

## 运行

直接双击 `index.html` 就能玩。

想用本地服务器（推荐，字体加载更稳）：

```bash
node tools/serve.mjs          # http://127.0.0.1:8123/
```

## 操作

| 按键 | 功能 |
| --- | --- |
| `←` `→` / `A` `D` | 左右移动 |
| `↓` / `S` | 蹲下（变大后）；站在水管上按下可进入水管 |
| `空格` / `Z` / `K` | 跳跃（**按住跳更高**，和原作一样） |
| `Shift` / `X` / `J` | 奔跑；吃到火花后发射火球 |
| `Enter` | 开始 / 过关后继续 / 重新开始 |
| `P` | 暂停（音乐自动降音） |
| `M` | 静音开关 |
| `R` | 放弃当前生命，重开本关 |

手机/平板会自动显示虚拟按键。

## 已实现的玩法

**角色状态**
- 小马里奥 → 吃蘑菇变大 → 吃火花变火焰马里奥（可以发射火球，火球会弹跳、能烧死敌人）
- 吃星星短时间内无敌，碰到敌人直接撞飞，颜色闪烁
- 变大后被敌人碰到只会变小并短暂无敌，变小状态下被碰到才会死

**砖块与问号块**
- 从下面顶问号块：出金币（+200）、蘑菇、火花、星星，或者 1UP
- **变大后顶砖块能把砖块顶碎**（4 块旋转碎片飞出，+50）；小马里奥只能顶一下把砖块顶起
- 顶砖块时站在砖块上面的敌人会被震翻
- 顶出 100 枚金币加一条命

**敌人**
- 栗宝宝（Goomba）：踩一脚踩扁 +100
- 乌龟（Koopa）：踩一脚变成龟壳，再碰一下把壳踢飞；飞行的壳能连撞其它敌人，每撞一个 +500
- 壳滑行撞墙会反弹，踩住滑行的壳能让它停下
- 壳滑出屏幕外会自动消失

**关卡**
- `1-1` 地上关，按原作布局还原：问号块阵、水管、隐藏的 1UP 砖、两段阶梯、旗杆 + 城堡
- `1-2` 地下关：黑底、蓝砖、砖砌天花板，`x=46` 的水管可以钻进去传送到 地下关，地下关 `x=64` 的水管能传回地上；地下关终点是斧头
- `1-3` 水上关：蓝色水面、浮空平台（会左右/上下移动，可以站在上面被带着走）、金币环

**其它细节**
- 復刻原作的惯性物理：走 / 跑速度分级、刹车转向有打滑帧、按住跳键跳得更高（SMB1 式的变高跳跃）
- 顶砖块 / 问号块有弹起动画；金币从块里蹦出来
- 旗杆：碰到旗杆滑下来，旗子升起，然后自动走进城堡，按时间结算奖励分
- 掉进坑或水里会死；时间到会死；命数用完 Game Over
- 摄像机只向右推进（和原作一致），垂直方向有死区跟随
- HUD 显示分数 / 金币 / 世界 / 时间 / 剩余命数

## 项目结构

```
index.html          页面外壳 + HUD
css/style.css       街机外壳样式（本地 Press Start 2P 像素字体）
js/sprites.js       全部精灵的像素画数据 + 打包成 atlas + paint 接口
js/audio.js         WebAudio 程序化音效 + 芯片音乐（3 首循环曲目）
js/levels.js        3 个关卡的瓦片/敌人/装饰数据
js/game.js          物理、碰撞、实体、砖块、道具、渲染、游戏状态机
js/main.js          启动、键盘/触摸输入、60Hz 固定步长主循环
assets/             Press Start 2P 字体（离线，无网络请求）
tools/              开发与测试工具（见下）
```

## 开发工具

```bash
node tools/smoke.mjs                 # 无头逻辑回归测试：52 项检查，覆盖全部核心玩法
node tools/preview-art.mjs           # 精灵图结构校验 + 终端 ASCII 预览
node tools/render-art.mjs out.png 6  # 把所有精灵渲染成一张 PNG 对照图
node tools/serve.mjs 8123            # 本地静态服务器
node tools/debug.mjs <scenario>      # 单场景逐帧追踪
```

`tools/debug.mjs` 支持 `land`（落地）、`bump`（顶问号块）、`pipe`（进水管）、`koopa`（踩乌龟）、
`levels`（关卡统计）几个场景，输出逐帧状态，方便排查手感/碰撞问题。

浏览器里也可以自测：启动 `tools/serve.mjs` 后打开 `http://127.0.0.1:8123/tools/selftest.html`，
页面会真机跑 600 帧并把结果打印在页面上（无头逻辑测试用的是假 canvas，这个用的是真 canvas）。

`tools/smoke.mjs` 用一个假的 canvas 在 Node 里把真游戏跑起来，检查：落地、撞墙不穿模、
顶问号块出蘑菇并吃大、变大顶碎砖块、踩栗宝宝、踩乌龟变壳并踢飞、滑壳连撞敌人、
火花升级并发射火球、受伤变小、星星无敌、掉坑死亡、进水管传送、旗杆过关、蹲下缩小判定框、
敌人不会卡在墙里等。

## 说明

- 图形与音频全部为原创实现（手写像素画 / 振荡器合成音），未使用任何任天堂素材。
- 之所以拆成多个 `<script>`（而不是 ES module），是为了双击 `index.html` 也能直接运行。
